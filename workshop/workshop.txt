title=Project Remnants AI 대화 한국어 변환
description=Project Remnants의 AI 대화에서 한국어 표현을 행동 명령으로 연결하고, 현재 상황 전달을 보완합니다.
description=
description=[b]주요 기능[/b]
description=• 따라와, 대기, 휴식, 식량, 입어·껴 등 설정된 한국어 키워드를 기존 행동 명령에 연결합니다.
description=• NPC의 실내·차량·착석 상태와 가까이 보이는 좀비 수를 외부 대화 도구에 전달합니다.
description=• 외부 도구에는 AI 연결·대화 보완과 NPC 프로필 불러오기·편집·저장 확인 기능이 포함됩니다.
description=
description=[b]필요한 구성[/b]
description=Project Zomboid Build 42와 [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3738362476]Project Remnants[/url]가 필요합니다. 원본 페이지의 설치 안내를 먼저 완료하세요.
description=이 창작마당 항목은 게임 안의 한국어 명령과 상황 수집을 담당합니다. AI 연결은 게임 밖의 Project Remnants Setup과 AI 대화 변환기를 함께 사용합니다.
description=[url=https://github.com/Hotsco/project-remnants-ai-korean/releases/latest]외부 도구 다운로드 및 설치 안내[/url]
description=사용할 서비스의 API 키와 사용 권한이 필요하며, 요금은 해당 서비스의 API 기준을 따릅니다.
description=
description=[b]사용 방법[/b]
description=1. 원본 모드와 이 모드를 구독하고 사용할 세이브에서 활성화합니다.
description=2. 외부 도구 ZIP을 모두 풀고 Start-Setup-And-Luna.cmd를 실행합니다. 창작마당에서 구독했다면 Install-Korean-Addon.cmd는 실행하지 않습니다.
description=3. Setup의 LLM Companion에서 OpenAI-compatible API를 선택하고 API 주소·키·모델을 설정한 뒤 Configure and Start를 누릅니다.
description=4. 원본의 LLM 대화와 행동 사용 옵션을 켜고 플레이합니다. Setup과 변환기는 실행 상태로 두세요.
description=NPC 프로필은 Open-NPC-Settings.cmd에서 편집합니다. 저장할 때는 게임을 완전히 종료하세요.
description=
description=[b]명령과 상황 인지[/b]
description=전체 키워드와 입력 예시, AI가 읽을 수 있는 상황은 다운로드한 도구의 GUIDE.html에서 확인할 수 있습니다.
description=AI는 화면이나 모든 소리를 직접 보고 듣지 않습니다. 가이드의 목록 밖 실시간 상황은 거의 직접 인지하지 못하며, 목록 안의 정보도 매 대화에 전부 전달되지는 않습니다.
description=특정 행동을 하는 개체를 골라 공격하는 기능은 구현되지 않았습니다. 예: 달리는 좀비만 공격.
description=실제 행동은 Remnants의 실행 조건을 따릅니다. 대사로 수락해도 행동이 완료됐다는 뜻은 아닙니다.
