좀보이드 NPC 한국어 명령 키워드

현재 배포본의 기본 키워드 목록입니다. 직접 낱말 설정을 바꿨다면 설치된 설정이 우선합니다.
대화 중인 NPC에게 한 번에 한 동작씩 요청하세요. 앞에 - 표시를 붙일 필요는 없습니다.
「휴식하자」는 명령으로, 「아까 휴식하자고 했잖아」는 일반 대화로 보냅니다. 키워드와 정해진 규칙으로 구별하므로 모든 한국어 문맥을 이해하지는 못합니다.
원본의 대화·LLM 행동 사용 옵션을 켜세요. 실제 실행에는 물건·거리·경로·관계·업무·차량 등 조건이 필요합니다. AI의 수락 대사는 행동 완료를 뜻하지 않습니다.
예시의 장소·보관함·요리·물건 이름은 실제로 렘넌츠가 식별할 수 있는 이름으로 바꾸세요. 장소 이름을 말하는 것만으로 새 목적지나 순찰 경로가 등록되지는 않습니다.

실행 확인 응답
렘넌츠가 실행 확인을 요청했을 때만: 수락은 「응 / 그래 / 네 / 좋아 / 확인 / 해 / 해줘」, 취소는 「아니 / 아니요 / 취소 / 하지마」입니다. 이때 「확인」은 수락이며, 평소의 「냉장고 확인」은 보관함 검사 명령입니다.

기본 명령은 편집 없이 사용할 수 있습니다. 낱말을 바꾸려면 사용자 데이터 폴더의 mods/ProjectRemnants_KoreanCommands/42/media/lua/client/NPCFW_KoreanCommandConfig.lua를 편집합니다. Lua 코드이므로 복사본을 만들고 따옴표·쉼표를 유지하세요. Install-Korean-Addon.cmd는 기존 낱말 설정을 보존합니다.
